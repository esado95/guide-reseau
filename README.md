# Семь слоёв стенда

Руководство по самостоятельной сборке сетевого стенда: VLAN и маршрутизация,
адресация и имена, выход в интернет, публикация сервиса и ограничение доступа.

Одна страница без зависимостей — открывается как локальный файл и как сайт.

## Где учиться по нему

Гайд загружен в Gemini Notebook как Google-документ из Drive. Из него сделаны:

- пять видео по частям — обзор, диагностика, VLAN, адреса и имена, граница сети (всего около 40 минут);
- аудиообзор на 27 минут для прослушивания в дороге;
- презентация, инфографика, майнд-карта, конспект;
- шпаргалка-таблица по сегментам сети, 80 карточек и тест на 30 вопросов.

Готовый материал там не обновляется сам: после правки гайда надо обновить документ в Drive,
нажать синхронизацию в блокноте и пересобрать те материалы, где изменение важно.

## Особенности

- **Скрыть команды** — кнопка вверху убирает листинги, оставляя названия шагов
  и проверки. Второй проход метода: команды восстанавливаешь по памяти.
- **Отметки** в контрольных проверках сохраняются в браузере, прогресс виден слева.
- Светлая и тёмная темы следуют настройке системы.

## Публикация

Страница самодостаточна: единственная внешняя зависимость — шрифты Google Fonts,
без них сработает системная подстановка.

GitHub Pages: `Settings` → `Pages` → источник `Deploy from a branch`,
ветка `main`, папка `/ (root)`. Адрес появится через минуту.

## Оговорка

Принципы вендоронезависимы. Примеры команд приведены для распространённых
платформ и требуют сверки с документацией конкретной прошивки: синтаксис
меняется от версии к версии.
